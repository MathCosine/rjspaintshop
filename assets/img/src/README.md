# Drop original images here

Name each file after its slot (any of .jpg, .png, .webp works):

| File | Shape |
|------|-------|
| `hero` | 3:2 landscape |
| `hero-mobile` | 4:5 portrait (optional, otherwise cut from `hero`) |
| `service-collision` | 4:5 portrait |
| `service-paint` | 4:5 portrait |
| `service-tesla` | 4:5 portrait |
| `service-dent` | 4:5 portrait |
| `about` | 4:5 portrait |
| `texture` | 16:9 landscape |
| `cta` | 16:9 landscape |

Then run `npm run images` and commit `assets/img/`. Prompts for each image are in [/ASSETS.md](../../../ASSETS.md).
